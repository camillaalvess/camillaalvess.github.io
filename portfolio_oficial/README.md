# 🌐 Meu Portfólio — Camilla Vitória

Portfólio pessoal desenvolvido para apresentar minha trajetória acadêmica, projetos, habilidades e experiências na área de tecnologia.

Sou estudante de **Análise e Desenvolvimento de Sistemas**, com foco em **Desenvolvimento Front-End, desenvolvimento web e UI/UX Design**. Este projeto foi criado com o objetivo de reunir meus principais trabalhos e demonstrar, na prática, minha evolução e conhecimentos em tecnologia.

> 💡 **Projeto adaptável:** embora este portfólio tenha sido desenvolvido para apresentar meu perfil profissional, sua estrutura pode ser facilmente adaptada para outros profissionais e áreas de atuação, bastando personalizar os conteúdos, projetos, informações e identidade visual.

---

## ✨ Sobre o Projeto

O portfólio foi desenvolvido com foco em uma experiência de navegação **simples, moderna, responsiva e intuitiva**.

A proposta é apresentar informações profissionais de forma organizada, permitindo que recrutadores, empresas e outros profissionais conheçam rapidamente minha trajetória, minhas principais habilidades e os projetos que venho desenvolvendo.

O projeto também busca aplicar conceitos de:

* Desenvolvimento Front-End
* Design responsivo
* UI/UX
* Organização de código
* Estrutura semântica
* Experiência do usuário
* Boas práticas de desenvolvimento web

## 🚀 Como Executar o Projeto

Por ser um projeto desenvolvido com HTML, CSS e JavaScript, não é necessário realizar uma instalação complexa.

### 1. Clone o repositório

```bash
git clone https://github.com/camillaalvess/Meu_portf-lio
```

### 2. Acesse a pasta

```bash
cd Meu_portf-lio
```

### 3. Execute o projeto

Você pode abrir diretamente o arquivo:

```text
index.html
```

no navegador.

Também é possível utilizar um servidor local.

### Com Python

```bash
python -m http.server 8000
```

Depois, acesse:

```text
http://localhost:8000
```
